01Aetheris PlatformIdentity, resilience and deployment in one backend.In development

The problem

How do you grow beyond a CRUD application while keeping authentication, service communication and failures understandable?

The approach

Build incrementally around a Spring Boot gateway, identity, user and audit services. Use Redis for shared caching and rate limiting, and RabbitMQ for asynchronous events.

Engineering evidence

  • JWT access tokens and rotating refresh tokens with hashed storage.
  • Structured failures, timeouts and circuit breakers.
  • Docker Compose and Helm deployment configuration, plus metrics and tracing.

The repository documents local deployment milestones. The next milestone is validating production hardening before expanding the AI-agent roadmap.

02FloodGuardSensor states become actionable alerts.Academic prototype

The problem

Sensor readings only become useful when people can understand changing risk and distinguish fresh information from stale or invalid data.

The approach

Connect Arduino and ESP8266 sensing to Firebase, then consume state in a Node.js notification service. Keep physical gate control on the embedded controller.

Engineering evidence

  • State-transition alerts and recovery notifications.
  • Stale-data protection and explicit sensor-error states.
  • Subscriber commands, persistent authentication and PM2 deployment notes.

The linked repository covers the cloud notification layer. This is an academic prototype, not a certified emergency warning service.

03AnyDL Pro UltraNative media tools, coordinated in a desktop UI.Desktop project

The problem

Native media tools are powerful, but coordinating their processes and reporting real progress needs more than a polished frontend.

The approach

Use a React and TypeScript interface, a typed Electron bridge, and main-process orchestration of yt-dlp and FFmpeg.

Engineering evidence

  • Metadata analysis and CLI progress parsing.
  • Renderer-to-main separation through contextBridge.
  • Persistent settings, native folder selection and Windows packaging.

The release path is clear: add automated lifecycle tests, then ship versioned Windows builds. AI upscaling remains a separate experiment.
