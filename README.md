# Poojana Kaveesh — Personal Portfolio

A responsive, recruiter-focused static portfolio website for **Poojana Kaveesh Sellahewa**.

## Included

- Modern responsive landing page
- Dark / light theme toggle
- Animated project presentation
- Project-category filters
- About and education section
- Skills grouped by engineering domain
- Current engineering roadmap
- GitHub and LinkedIn links
- SEO and Open Graph metadata
- Schema.org `Person` structured data
- Accessibility basics and reduced-motion support
- No build step required

## Local preview

Open `index.html` directly in a browser, or serve the folder with any local static server.

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Free hosting

This project is ready for GitHub Pages, Cloudflare Pages, or Vercel. Because it is plain HTML/CSS/JavaScript, no build command is required.
